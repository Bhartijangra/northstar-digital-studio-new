# Northstar Digital Studio (demo)
Plain HTML/CSS/JS. Open index.html or run `python -m http.server`.

## Deploy
Netlify: drag this folder to app.netlify.com/drop. GitHub Pages: push, then Settings > Pages. Cloudflare Pages: connect the repo (no build command).

## After deploying
Replace https://northstar-digital-demo.netlify.app/ with your real URL in all HTML canonical/og tags, sitemap.xml and robots.txt (find and replace).

## Simulated
Contact form, all metrics and case studies, team and contact details are fictional. Real forms need a backend or form service.
